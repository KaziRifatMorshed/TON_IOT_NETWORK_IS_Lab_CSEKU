# Agent Guidelines: NVIDIA-Themed Academic Presentation (Manim & Manim-Slides)

This document establishes the architecture, design principles, color palette, technical specifications, and development workflows for generating thesis defense slides and animations in this repository.

The presentation is built for an **Academic Thesis Defense** with **NVIDIA Brand Identity**, executed strictly in a **Light Theme** (clean `#F8FAFC` / `#FFFFFF` canvas, high-contrast typography, and accessible visual hierarchy).

---

## 1. Brand Color Palette (Light Academic Defense Theme)

Strictly adhere to the following color palette. Never use dark mode backgrounds or arbitrary unapproved colors.

### Color Definitions

| Role | Variable Name | Hex Code | Purpose & Usage |
| :--- | :--- | :--- | :--- |
| **Signature Brand** | `NVIDIA_GREEN` | `#76B900` | Official NVIDIA Green (Pantone 376/382 C). Global footer bar, top header accent rule, title underline, card accent stripe, active GPU blocks, status bullet dots. |
| **Accessible Dark Green** | `NVIDIA_DARK_GREEN` | `#265200` | High-contrast green for text on light background (WCAG AAA compliant, > 7:1 contrast). Completion status captions, supervisor labels, discipline header text. |
| **Accent Green** | `NVIDIA_ACCENT_GREEN`| `#3B7500` | Structural borders for active blocks, footer separators, and geometric outlines. |
| **Primary Typography** | `TEXT_MAIN` | `#1A1A1A` | Deep charcoal for slide titles, presenter names, LaTeX equations, and core text. Preserves 16:1 contrast without harshness. |
| **Secondary Typography**| `TEXT_MUTED` | `#525B64` | Slate gray for secondary captions, subtitles, supervisor names, dates, and notes. |
| **Base Canvas** | `CARD_BG` | `#F8FAFC` | Official light theme base canvas and footer text color. |
| **Pure White** | `WHITE` | `#FFFFFF` | Card surface fill, content header bar fill, and bold text inside active green blocks. |
| **Container Border** | `CARD_BORDER` | `#E2E8F0` | Hairline boundary stroke for technical cards and header dividers. |
| **Inactive Block Fill** | `BLOCK_INACTIVE_FILL`| `#F1F5F9` | Neutral hardware slate/titanium fill for inactive or unpartitioned GPU units. |
| **Inactive Block Stroke**| `BLOCK_INACTIVE_STROKE`| `#94A3B8`| Neutral hardware border for unactivated components. |

## 4. Technical Requirements (Manim & Manim-Slides)

1. **Camera Background Color Type Safety**:
   - **Do NOT** set `self.camera.background_color = "#F8FAFC"` (raw string).
   - **ALWAYS** set `self.camera.background_color = ManimColor(CARD_BG)`.
   - *Reason*: `manim_slides` calls `.to_hex()` on `self.renderer.camera.background_color`. Passing a raw Python `str` causes a fatal `AttributeError: 'str' object has no attribute 'to_hex'`.

2. **Default LaTeX Configuration**:
   - Manim's default color for `Tex` and `MathTex` is `#FFFFFF`. On light backgrounds, unstyled LaTeX is invisible.
   - Always declare:
     ```python
     config.background_color = ManimColor(CARD_BG)
     Tex.set_default(color=TEXT_MAIN)
     MathTex.set_default(color=TEXT_MAIN)
     ```

3. **Preventing Text Ghosting**:
   - Do **NOT** use `Transform(old_text, new_text)` between text mobjects of differing string lengths or glyph points.
   - Use `FadeOut(old_text)` + `FadeIn(new_text)` within `self.play(...)`, or use `.animate.set_color(...)`.
   - Add a brief `self.wait(0.2)` at the end of transition animations to ensure 100% completion in exported video segments.

## 5. Build, Render & Present CLI Workflows

Always execute commands inside the conda environment (`manim_env`).

### 1. High-Quality 1080p60 Render
```bash
conda activate manim_env
cd presentation
manim -qh presentation_slides.py TonIoTPresentation
```

### 2. Export to Light-Themed Reveal.js HTML
```bash
manim-slides convert TonIoTPresentation ton_iot_presentation.html -c reveal_theme=white
```

### 3. Interactive Fullscreen Presentation Mode
```bash
manim-slides TonIoTPresentation
```
*(Controls: `Space` or `Right Arrow` to advance, `Left Arrow` to step back, `F` for fullscreen, `Q` to quit).*

### 4. Or Use One-Click Helper Script
```bash
./render_presentation.sh html     # Fast render and HTML export
./render_presentation.sh full-hd  # 1080p60 Full HD render and HTML export
./render_presentation.sh present  # Launch interactive fullscreen player
```
