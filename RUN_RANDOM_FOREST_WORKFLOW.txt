How to Run the Random Forest Network Classification Workflow
============================================================

1. Open Command Prompt.

2. Go to the project folder:

   cd /d "G:\Academic\4th year 1 term\Information Security\Ton_IoT Network"

3. Optional quick test on a small sample:

   .venv\Scripts\python.exe -m src.random_forest_workflow --sample-size 3000 --n-estimators 20 --n-jobs 1

4. Run the full Random Forest workflow:

   .venv\Scripts\python.exe -m src.random_forest_workflow

5. Run with hyperparameter tuning:

   .venv\Scripts\python.exe -m src.random_forest_workflow --tune

Generated Outputs
=================

After the script finishes, check these files:

- Trained model:
  models\rf_network_classifier.joblib

- Classification report:
  outputs\reports\rf_workflow_classification_report.txt

- Summary JSON:
  outputs\reports\rf_workflow_summary.json

- Feature importance CSV:
  outputs\reports\rf_workflow_feature_importance.csv

- Confusion matrix plot:
  outputs\figures\rf_workflow_confusion_matrix.png

- Feature importance plot:
  outputs\figures\rf_workflow_feature_importance.png

Notes
=====

- The default dataset path is dataset.csv in the project root.
- The workflow classifies traffic into three classes: normal, dos, and ddos.
- It follows the PDF workflow: remove duplicates, convert IP addresses to numeric values, label-encode categorical columns, remove constant columns, split 80/20, train Random Forest, evaluate, save feature importance, and save the model.
- If dependencies are missing, install them with:

  .venv\Scripts\python.exe -m pip install -r requirements.txt
